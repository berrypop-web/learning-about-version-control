# Learning about Version Control
Author: Lise Gong

Solving merge conflicts takes conscious effort, but I can do it!

What I like most about version control is how it connects everyone's work asynchronously, so people can collaborate on the same files without being in the same room. Working on our group project milestone this way made me feel like a real data scientist.

What I find most challenging is keeping track of where I am: which branch I'm on, what's been committed, and what's been pushed, since git doesn't tell you unless you ask.
